# Checklist de Operação

Use depois da publicação e durante a manutenção.

---

## Monitoramento

- [ ] O sistema possui logs acessíveis.
- [ ] Erros em produção são monitorados.
- [ ] Há forma de medir disponibilidade.
- [ ] Há forma de medir uso.

---

## Infraestrutura

- [ ] DNS está documentado.
- [ ] HTTPS está válido.
- [ ] Custos e limites do serviço são conhecidos.
- [ ] Backups existem quando há dados.

---

## Manutenção

- [ ] Dependências são atualizadas periodicamente.
- [ ] Pendências são registradas.
- [ ] Incidentes são documentados.
- [ ] Há plano de rollback ou restauração.
