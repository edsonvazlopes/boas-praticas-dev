# Privacidade e LGPD

Privacidade é próxima de segurança, mas não é a mesma coisa.

Segurança pergunta: *como impedir acesso indevido?*
Privacidade pergunta: *eu realmente preciso coletar esse dado, por quanto tempo, com qual base legal, e o usuário sabe disso?*

---

## O que entra nesse pilar

```txt
LGPD
política de privacidade
termos de uso
cookies
analytics
formulários
retenção de dados
exclusão de conta
consentimento
```

Para qualquer site público profissional, esse pilar deve existir desde o início — não é algo para "resolver depois".

Itens de implementação (cookie banner, páginas legais, checklist de publicação) ficam detalhados no [checklist de publicação](../06-publicacao-seo-performance/checklist-seo-performance-publicacao.md#19-privacidade-lgpd-e-confiança).

---

## Checklist

- [ ] O projeto coleta apenas dados necessários (minimização).
- [ ] Há política de privacidade.
- [ ] Há termos de uso quando necessário.
- [ ] Cookies e analytics foram avaliados quanto à necessidade de consentimento.
- [ ] Formulários deixam claro o destino dos dados.
- [ ] Existe política de retenção.
- [ ] Existe caminho para exclusão ou correção de dados quando aplicável.
- [ ] A base legal para cada tratamento de dado está clara.
