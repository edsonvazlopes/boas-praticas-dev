# Uso Responsável de IA no Desenvolvimento

IA pode acelerar desenvolvimento, revisão e documentação, mas não substitui responsabilidade técnica.

---

## Boas práticas

- revisar todo código gerado;
- pedir explicação quando não entender;
- exigir testes;
- verificar segurança;
- não colar segredos em prompts;
- não enviar dados sensíveis sem autorização;
- validar comandos antes de executar;
- comparar com documentação oficial quando houver dúvida.

---

## Usos recomendados

```txt
gerar primeiro rascunho
explicar código legado
sugerir testes
criar documentação
revisar checklist
comparar abordagens
ajudar em refatoração
```

---

## Riscos

```txt
código inseguro
dependência inexistente
API desatualizada
solução complexa demais
vazamento de dados
confiança excessiva
```

---

## Checklist

- [ ] Entendi o código gerado?
- [ ] Testei o comportamento?
- [ ] Revisei segurança?
- [ ] Conferi documentação oficial quando necessário?
- [ ] Removi dados sensíveis do prompt?
- [ ] O resultado combina com o padrão do projeto?
