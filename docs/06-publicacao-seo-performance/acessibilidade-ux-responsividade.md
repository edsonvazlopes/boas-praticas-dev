# UX, Acessibilidade e Responsividade

Esse pilar responde:

```txt
A pessoa consegue usar?
No celular funciona?
O texto é legível?
O contraste é bom?
Dá para navegar pelo teclado?
Os botões são claros?
```

Em um site ou sistema público, o visitante decide em poucos segundos se fica ou sai — esse pilar não é um polimento final, é parte do produto.

---

## O que entra

```txt
layout mobile
hierarquia visual
contraste
semântica HTML
alt em imagens
formulários claros
feedback de erro
estados de loading
navegação simples e por teclado
```

O checklist detalhado de verificação fica na [seção 16 e 17 do checklist de publicação](../06-publicacao-seo-performance/checklist-seo-performance-publicacao.md#16-responsividade-e-mobile-first) (responsividade e acessibilidade). Use este documento como referência conceitual e aquele como lista de verificação antes de publicar.

---

## Checklist rápido

- [ ] O site/sistema funciona bem no celular.
- [ ] A navegação é clara e utilizável por teclado.
- [ ] O contraste é adequado.
- [ ] Imagens relevantes têm texto alternativo.
- [ ] O HTML usa semântica adequada.
- [ ] Formulários têm mensagens de erro claras.
- [ ] Estados de carregamento e erro foram considerados.
