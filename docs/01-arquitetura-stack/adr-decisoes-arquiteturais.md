# ADR - Registro de Decisões Arquiteturais

ADR significa Architecture Decision Record.

É um documento curto que registra uma decisão importante de arquitetura, o contexto que levou a ela e suas consequências.

---

## Quando criar um ADR

- escolha de banco de dados;
- escolha de framework;
- mudança de arquitetura;
- adoção de fila, cache ou serviço externo;
- decisão de deploy;
- estratégia de autenticação;
- escolha de padrão de organização do projeto.

---

## Estrutura recomendada

```txt
Título
Status
Contexto
Decisão
Consequências
Alternativas consideradas
Data
Responsável
```

---

## Checklist

- [ ] A decisão afeta o futuro do projeto?
- [ ] O contexto foi explicado?
- [ ] A decisão foi registrada?
- [ ] Consequências positivas e negativas foram anotadas?
- [ ] Alternativas foram consideradas?
