# Checklist de Arquitetura

Use este checklist ao iniciar ou revisar um projeto.

---

## Escopo

- [ ] O objetivo do sistema está claro.
- [ ] O MVP foi definido.
- [ ] As principais telas ou rotas foram listadas.
- [ ] Os fluxos principais foram descritos.

---

## Estrutura

- [ ] A stack foi escolhida.
- [ ] A estrutura de pastas tem lógica.
- [ ] Camadas ou módulos foram definidos.
- [ ] O padrão de nomes está claro.
- [ ] Decisões importantes foram registradas.

---

## Dados e integrações

- [ ] Entidades principais foram mapeadas.
- [ ] Banco de dados foi escolhido.
- [ ] Integrações externas foram listadas.
- [ ] Estratégia de backup foi considerada.

---

## Evolução

- [ ] Há espaço para crescimento sem reescrever tudo.
- [ ] A arquitetura não está exagerada para o projeto.
- [ ] Há caminho de deploy definido.
- [ ] Há estratégia mínima de teste e manutenção.
