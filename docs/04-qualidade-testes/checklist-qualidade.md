# Checklist de Qualidade

Use antes de considerar uma entrega pronta.

---

## Build e verificação

- [ ] Build executa sem erro.
- [ ] Lint executa sem erro crítico.
- [ ] Tipagem executa sem erro, quando aplicável.
- [ ] Dependências estão instaladas e documentadas.

---

## Testes

- [ ] Regras importantes foram testadas.
- [ ] Fluxos principais foram testados manualmente ou por E2E.
- [ ] Formulários foram testados.
- [ ] Erros esperados foram testados.

---

## Experiência

- [ ] Layout foi testado em celular.
- [ ] Estados de loading foram considerados.
- [ ] Mensagens de erro são claras.
- [ ] Links principais funcionam.

---

## Manutenção

- [ ] README foi atualizado.
- [ ] `.env.example` foi atualizado.
- [ ] Deploy foi documentado.
- [ ] Pendências conhecidas foram registradas.
