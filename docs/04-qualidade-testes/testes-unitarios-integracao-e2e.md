# Testes Unitários, Integração e E2E

Cada tipo de teste responde uma pergunta diferente.

---

## Teste unitário

Pergunta:

```txt
Essa regra isolada funciona?
```

Exemplo:

```txt
calcular média
validar CPF
calcular total de pedido
verificar permissão
```

---

## Teste de integração

Pergunta:

```txt
Essas partes funcionam juntas?
```

Exemplo:

```txt
rota cria usuário no banco
login gera sessão
API grava lançamento financeiro
```

---

## Teste E2E

Pergunta:

```txt
O fluxo real funciona para o usuário?
```

Exemplo:

```txt
usuário cadastra, entra, cria item e vê resultado na tela
```

---

## Checklist

- [ ] O tipo de teste escolhido combina com o risco?
- [ ] Casos felizes e casos de erro foram pensados?
- [ ] O teste é legível?
- [ ] O teste falha quando o comportamento quebra?
- [ ] O teste não é frágil demais?
